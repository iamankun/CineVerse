# CineVerse v1.2.2 - Nguồn Phim Nội Bộ

**Ngày phát hành:** 24/10/2025

## 🎉 Tính năng mới: Hệ thống Nguồn Phim Nội Bộ

### Tổng quan
CineVerse giờ đây hỗ trợ **nguồn phim nội bộ** từ YouTube và Dailymotion, được **ưu tiên tuyệt đối** trước tất cả các player khác (VidLink, Embed, VidSrc...).

### Cải tiến chính

#### 1. 📁 Cấu trúc Thư mục Nguồn
```
public/sources/
├── Movie/           # Phim điện ảnh (JSON files theo TMDB ID)
├── ChuongTrinhTV/   # Chương trình TV (seasons/episodes)
└── README.md        # Hướng dẫn chi tiết
```

#### 2. 🔌 API Routes Mới
- `GET /api/sources/movie/{id}` - Lấy nguồn phim
- `GET /api/sources/tv/{id}?season={s}&episode={e}` - Lấy nguồn TV

#### 3. 🎯 Ưu tiên Nguồn
**TRƯỚC:**
```
1. VidLink (Recommended)
2. VidLink 2 (Recommended)
3. Embed
4. ...
```

**SAU:**
```
1. ⭐ CineVerse YouTube 1080p (Recommended, Fast, No Ads)
2. ⭐ CineVerse Dailymotion 720p (Recommended, Fast, No Ads)
3. VidLink
4. VidLink 2
5. Embed
6. ...
```

#### 4. 📝 Format JSON

**Phim:**
```json
{
  "tmdbId": 27205,
  "title": "Inception",
  "sources": [
    {
      "provider": "youtube",
      "title": "YouTube HD",
      "url": "https://www.youtube.com/embed/VIDEO_ID",
      "quality": "1080p",
      "language": "en",
      "subtitles": ["vi", "en"]
    }
  ],
  "lastUpdated": "2025-10-24T00:00:00Z"
}
```

**TV Shows:**
```json
{
  "tmdbId": 1396,
  "title": "Breaking Bad",
  "seasons": {
    "1": {
      "1": { "sources": [...] },
      "2": { "sources": [...] }
    }
  }
}
```

### Cách sử dụng

#### Thêm phim mới:
1. Tìm TMDB ID (ví dụ: Inception = 27205)
2. Tạo file `public/sources/Movie/27205.json`
3. Lấy YouTube/Dailymotion embed URL
4. Điền vào JSON theo template
5. Deploy: `npx vercel --prod`

#### Kiểm tra:
- Phim: `/movie/27205/player`
- TV: `/tv/1396/1/1/player`

Nguồn CineVerse sẽ hiển thị đầu tiên với badge **Recommended ⭐**

### Lợi ích

✅ **Kiểm soát hoàn toàn** nguồn phim  
✅ **Không quảng cáo** (YouTube/Dailymotion embed)  
✅ **Tốc độ nhanh** (CDN YouTube/Dailymotion)  
✅ **Chất lượng cao** (1080p+)  
✅ **Phụ đề đa ngôn ngữ**  
✅ **Dễ quản lý** (chỉ cần upload JSON)  

### Breaking Changes
❌ **KHÔNG CÓ** - Backward compatible 100%

Nếu không có file JSON cho phim, hệ thống tự động fallback về các player cũ.

### Migration Guide
Không cần migration. Tính năng hoạt động ngay khi deploy.
