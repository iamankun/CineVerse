# CineVerse v1.2.3 - Player Overlays & Branding

**Ngày phát hành:** 24/10/2025

## 🎉 Tính năng mới: Hệ thống Overlay Nâng cao

### Tổng quan
CineVerse giờ đây có **hệ thống overlay thông minh** hiển thị thông tin phim trong quá trình xem, bao gồm:
- 🏆 **Age Rating** - Phân loại độ tuổi (P, K, T13, T16, T18, C)
- 🎬 **Watching With Brand** - Logo phim từ TMDB
- 🌟 **CineVerse Logo** - Watermark thương hiệu

### Cải tiến chính

#### 1. 🔞 Hệ thống Age Rating (Phân loại độ tuổi)

**Tính năng:**
- Hiển thị phân loại độ tuổi theo chuẩn Việt Nam
- Mở rộng mô tả chi tiết mỗi 10 phút
- Luôn hiển thị icon "I" và rating, chỉ ẩn description

**Format hiển thị:**
```
[I] T16 ← Luôn hiển thị
[I] T16 - Phim dành cho khán giả từ 16 tuổi trở lên ← Mở rộng 5 giây
```

**Phân loại:**
- **P** - Phim dành cho mọi lứa tuổi
- **K** - Phim dành cho trẻ em dưới 13 tuổi xem cùng phụ huynh
- **T13** - Phim dành cho khán giả từ 13 tuổi trở lên
- **T16** - Phim dành cho khán giả từ 16 tuổi trở lên
- **T18** - Phim dành cho khán giả từ 18 tuổi trở lên
- **C** - Phim bị cấm chiếu trên mọi nền tảng

**Chu kỳ hiển thị:**
- Mở rộng mỗi **10 phút** theo thời lượng video
- Hiển thị mở rộng trong **5 giây**
- Thu gọn lại chỉ còn icon + rating

**Vị trí:** Góc trên bên trái player

#### 2. 🎬 Watching With Brand (Thương hiệu phim)

**Tính năng:**
- Hiển thị "Bạn đang xem [Logo phim]"
- Logo lấy từ TMDB API (ưu tiên: Tiếng Việt → Tiếng Anh → Bất kỳ)
- Fallback: Hiển thị tên phim nếu không có logo
- **TRACKING VIDEO TIME THỰC TẾ** - Bám theo thời lượng phim, không bị ảnh hưởng bởi tua/pause

**Chu kỳ hiển thị:**
- Hiển thị ngay khi bắt đầu xem (sau 1 giây)
- Lặp lại mỗi **30 phút** theo **thời lượng video**
- Hiển thị trong **15 giây**
- **Bám sát video time**: Dù có tua hay pause, vẫn đúng mốc thời gian video

**Tracking thông minh:**
- Nhận video time từ iframe qua postMessage (nếu player hỗ trợ)
- Fallback: Ước lượng dựa trên thời gian không idle
- Reset khi user tua video đến mốc thời gian mới

**Vị trí:** Góc dưới bên trái player

**Ví dụ:**
```
Bạn đang xem [DANDADAN logo]
Bạn đang xem [Inception logo]
Bạn đang xem Nhà Gia Tiên (nếu không có logo)
```

#### 3. 🌟 CineVerse Logo Watermark

**Tính năng:**
- Logo GIF động của CineVerse
- Luôn hiển thị ở góc trên phải
- Đồng bộ với Age Rating về visibility

**Vị trí:** Góc trên bên phải player

#### 4. 🎯 Hệ thống Visibility Thông minh

**Idle Detection:**
- Desktop: Ẩn overlays sau 3 giây không di chuyển chuột
- Mobile: Luôn hiển thị overlays
- Fullscreen: Luôn hiển thị overlays

**Đồng bộ:**
- Tất cả overlays (Age Rating, Logo, Watching With Brand) cùng show/hide
- Transition mượt mà với opacity animation
- Z-index cao nhất (2147483647) để luôn hiển thị trên iframe

## 🔧 Technical Details

### Video Time Tracking Logic

**Method 1: postMessage (Preferred)**
```typescript
window.addEventListener('message', (event) => {
  if (event.data.type === 'videoTime') {
    setVideoCurrentTime(event.data.time);
  }
});
```

**Method 2: Fallback Timer**
```typescript
// Only accumulate when NOT idle
if (!idle) {
  accumulatedTime += (Date.now() - startTime) / 1000;
  setVideoCurrentTime(Math.floor(accumulatedTime));
}
```

**Benefit:** Tracks actual playback time, unaffected by:
- Video seeking (tua)
- Video pausing
- User idle time
- Tab switching

### 30-Minute Cycle Implementation

```typescript
const videoMinutesElapsed = Math.floor(
  (videoCurrentTime - lastVideoTimeShown) / 60
);

if (videoMinutesElapsed >= 30 && !showMessage) {
  setShowMessage(true);
  setLastVideoTimeShown(videoCurrentTime);
  
  setTimeout(() => setShowMessage(false), 15000);
}
```

**Behavior:**
- 0:00 → Show immediately
- 30:00 → Show again
- 60:00 → Show again
- User seeks to 45:00 → Show again at 75:00 (30 min later)
