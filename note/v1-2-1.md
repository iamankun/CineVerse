## 🔧 Cải tiến kỹ thuật

### **Hệ thống ưu tiên ngôn ngữ hoàn chỉnh**

| **Loại**       | **Chiến lược ưu tiên**                       |
|----------------|----------------------------------------------|
| **Trailers**   | `vi` → `en` → ngôn ngữ khác                 |
| **Logos**      | `vi` → `en` → `null` → ngôn ngữ khác        |
| **Backdrops**  | `null` (no language) → sắp xếp theo rating  |

### **Helper Functions mới**

```typescript
// src/utils/helpers.ts

/**
 * Sắp xếp backdrops ưu tiên null (no language) trước, sau đó theo vote_average
 */
export const sortBackdrops = <T extends { iso_639_1: string | null; vote_average?: number }>(
  backdrops: T[]
): T[] => {
  if (!backdrops || backdrops.length === 0) return [];
  
  return [...backdrops].sort((a, b) => {
    // Ưu tiên backdrops không có ngôn ngữ (null)
    if (a.iso_639_1 === null && b.iso_639_1 !== null) return -1;
    if (a.iso_639_1 !== null && b.iso_639_1 === null) return 1;
    
    // Nếu cùng null hoặc cùng có language, sort theo vote_average
    const aVote = a.vote_average || 0;
    const bVote = b.vote_average || 0;
    return bVote - aVote; // Giảm dần (cao -> thấp)
  });
};
```

## 📝 Ghi chú bổ sung

### TMDB API Insights

> **Backdrop Images:** Theo tài liệu TMDB, 99% backdrops không chứa language tag (`iso_639_1 = null`), vì backdrop thường là hình ảnh phổ quát không có chữ. Do đó, logic ưu tiên của backdrop khác với logos.

### Best Practices

- Luôn kiểm tra `null`/`undefined` trước khi parse Date
- Sử dụng ternary operator hoặc optional chaining để xử lý fallback
- Với TV shows, cần xử lý cả ngày bắt đầu và kết thúc
